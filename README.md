# omnipha/linux-sm8250

Source-policy and work repo for the Qualcomm SM8250 kernel used by Omnipha.
First target device: OnePlus 8 Pro (`oneplus-instantnoodlep`, fleet unit `mb005`).

Tracking repo, not a kernel tree. The pinned upstream is the community mainline
fork `gitlab.postmarketos.org/soc/qualcomm-sm8250/linux` (packaged upstream as
`linux-postmarketos-qcom-sm8250`). See UPSTREAM.md and AGENTS.md.

Measured state: `status.yaml`. Evidence: one dated file per event in `records/`.
Next step: `PLAN.md`. Mission tracker: the epic in omnipha/ports.
